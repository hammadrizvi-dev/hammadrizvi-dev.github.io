## ⚡ Overview

This repository contains the production code for my personal website. Designed with a clean, dark-mode technical aesthetic, it serves as an interactive hub showcasing my **Data Science projects, Machine Learning sprints, academic background, and professional CV**.

- 🔗 **Production URL:** [https://hammadrizvi.tech](https://hammadrizvi.tech)
- 🔒 **Security & DNS:** SSL enforced with Cloudflare DNS proxying.

---

## 🛠️ Tech Stack

* **Core:** Semantic HTML5, Modular CSS3 (Custom Variables, Flexbox, CSS Grid).
* **Styling Paradigm:** Glassmorphism UI, Ambient radial glow, pure responsive design without heavy external frameworks (Zero Bloat).
* **Typography:** Plus Jakarta Sans & Fira Code (via Google Fonts).
* **Hosting & Infrastructure:** GitHub Pages + Custom Domain (`hammadrizvi.tech`) + Cloudflare DNS.

---

## 📂 File Architecture

The codebase is split into distinct, modular files to allow easy updates and scalable additions of new case studies:

```text
hammadrizvi-dev.github.io/
│
├── index.html          # Landing view: Hero section, tech stack snapshot, quick CTAs
├── projects.html       # Detailed project catalog with tech tags and direct repo links
├── about.html          # Academic background (B.Tech CS & Design), technical philosophy
├── style.css           # Central design system, CSS variables, responsive breakpoints
│
├── assets/
│   └── resume.pdf      # Professional Curriculum Vitae (CV)
│
├── CNAME               # Custom domain routing for hammadrizvi.tech
└── README.md           # Repository documentation
```

## ✨ Key Features

1. **Lightweight & High Performance:** 100% vanilla web stack — instant loading with zero JavaScript framework dependencies.

## 💻 Local Development

To run or tweak this website locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/hammadrizvi-dev/hammadrizvi-dev.github.io.git
   cd hammadrizvi-dev.github.io
   ```

2. **Open in browser:**
   * Simply double-click `index.html` to open it in any browser, or
   * Use VS Code's **Live Server** extension to preview live edits.
